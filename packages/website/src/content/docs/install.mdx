The simplest install path is one shell command:

<Code code={`/bin/sh -c "$(curl -fsSL https://downloads.contextbridge.ai/cli/install.sh)"`} lang="sh" title="terminal" />

The script picks up [Homebrew](https://brew.sh/) if you have it, otherwise downloads the release tarball into `$HOME/.local/bin`. After the binary lands, it runs `contextbridge install` interactively to add standard plugin or hook entries to any supported AI coding harness it detects. The `/bin/sh -c "$(curl ...)"` form preserves terminal input so you stay in control of those prompts.

See [Manual install](#manual-install) below if you'd rather drive it yourself.

## Manual install

Two steps either way: get the binary on your PATH, then run `contextbridge install` to add the harness plugin or hook entries.

### Step 1a: Homebrew (preferred)

<Code code="brew install contextbridge/tap/cli" lang="sh" title="terminal" />

### Step 1b: Tarball

If Homebrew isn't an option, grab the latest release tarball directly.

<TarballPlatformTabs />

### Step 2: Wire up the hooks

<Code code="contextbridge install" lang="sh" title="terminal" />

This detects every supported AI coding harness on your machine and adds the review hook or plugin entry using that harness's normal extension system. The curl one-liner runs this for you; both manual paths leave it as a separate step. See [the installer reference](/cli/install/) for flags and per-harness targeting.

Codex CLI requires newly installed hooks to be trusted before they can run. If you install the Codex hook, finish the [Codex trust walkthrough](/usage/codex/#trust-the-codex-hook) before expecting PlanBridge to open inside Codex.

## Verify

<Code code={`contextbridge --version
contextbridge install status`} lang="sh" title="terminal" />

`install status` reports which supported harnesses were detected and which currently have PlanBridge entries installed.

## Installer options

The install script accepts flags after `--`:

| Flag | Env var | What it does |
| --- | --- | --- |
| `--channel alpha` | `CB_CHANNEL` | Install from the alpha release channel instead of stable. |
| `--version v0.1.0` | `CB_VERSION` | Pin to a specific tagged release. Requires `--no-brew`. |
| `--no-brew` | `CB_NO_BREW=1` | Skip Homebrew even if available; fall through to the tarball path. |
| `--bin-dir <dir>` | `CB_INSTALL_DIR` | Override the tarball install dir (default `$HOME/.local/bin`). Requires `--no-brew`. |
| `--no-configure` | `CB_SKIP_CONFIGURE=1` | Skip the post-install `contextbridge install` step. Useful in CI. |

Pass flags after `--`:

<Code code={`/bin/sh -c "$(curl -fsSL https://downloads.contextbridge.ai/cli/install.sh)" -- --channel alpha`} lang="sh" title="terminal" />

## Update

<Code code="contextbridge update" lang="sh" title="terminal" />

Set `CONTEXTBRIDGE_UPDATE_CHECK_DISABLED=1` to silence the periodic update check.

## Uninstall

<Code code="contextbridge uninstall" lang="sh" title="terminal" />

Removes PlanBridge's plugin and hook entries from every harness, which gets your old workflow back. After that, remove the binary itself with the same package manager that installed it (Homebrew, or `rm $HOME/.local/bin/contextbridge`).

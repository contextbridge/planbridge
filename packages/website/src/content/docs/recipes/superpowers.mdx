[Superpowers](https://github.com/obra/superpowers) is a Claude Code and Codex plugin from Jesse Vincent that gives the agent a library of process skills (brainstorming, writing plans, executing plans, debugging). Two pause points in that workflow are good places to drop in PlanBridge for inline human review.

## During brainstorming

The brainstorming skill walks the agent through clarifying questions and presents the design back to you in sections, in the terminal. Pull the most recent section into PlanBridge by referring to it in plain language:

<Tabs syncKey="harness">
  <TabItem label="Claude Code">
    <Code code="/planbridge-open the section you just wrote" lang="text" />
  </TabItem>
  <TabItem label="Codex CLI">
    <Code code="$planbridge-open the section you just wrote" lang="text" />
  </TabItem>
</Tabs>

The agent resolves the reference, pipes the section to `contextbridge open` via stdin, opens PlanBridge, and feeds your inline annotations back into the brainstorming loop.

## Reviewing the spec

Once you approve the design, the brainstorming skill writes a spec file under `docs/superpowers/specs/` and pauses for review. Open it by description rather than path. The filename is dated and topic-specific, and superpowers documents the location as overridable by user preference, so a hard-coded path here would lie:

<Tabs syncKey="harness">
  <TabItem label="Claude Code">
    <Code code="/planbridge-open the spec you just wrote" lang="text" />
  </TabItem>
  <TabItem label="Codex CLI">
    <Code code="$planbridge-open the spec you just wrote" lang="text" />
  </TabItem>
</Tabs>

Same loop: annotate inline, submit, and the agent revises the spec or moves on to writing the plan.

## Notes

- Both flows work the same in Claude Code and Codex. Superpowers ships plugin manifests for both.
- Superpowers writes specs and plans directly to disk and never enters Claude Code's plan mode, so PlanBridge's automatic plan-mode hook does not fire here. `/planbridge-open` is the right entry point.
- See [Open arbitrary content](/usage/open/) for how `/planbridge-open` resolves natural-language references to conversation content and recently-written files.

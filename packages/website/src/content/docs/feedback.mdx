---

PlanBridge is open source and developed in the open. Pick the channel that matches what you want to do.

## Report a bug

Open a GitHub issue. Include the version (`contextbridge --version`), your harness (Claude Code, Codex), and the command or steps that triggered the bug.

**[File a bug report →](https://github.com/contextbridge/planbridge/issues/new?template=bug_report.yml)**

## Request a feature

Open a GitHub issue. Lead with the problem you are trying to solve, not the feature you imagine.

**[File a feature request →](https://github.com/contextbridge/planbridge/issues/new?template=feature_request.yml)**

## Ask questions or talk through ideas

Slack is the fastest way to reach the team for open-ended questions, workflow advice, or design conversations before you file an issue.

**[Join the ContextBridge Slack →](https://go.contextbridge.ai/join-community)**

## Email

For anything that does not fit a public channel, write to [`support@contextbridge.ai`](mailto:support@contextbridge.ai?subject=PlanBridge).
